# 医药国际业务个人站上线

## 做了什么

从零建立了一个与原个人主页完全独立的 Astro 静态网站和 GitHub 仓库 `jed-pharma-website`，完成英文默认、中文独立路由的 12 个页面，并把专业能力、重点市场、匿名案例、个人方法和联系方式组织成一套完整的医药国际业务叙事。站点保留 Jed 手写标识、深海军蓝和钴蓝，新头像作为首页主视觉；LinkedIn、邮箱和微信联系卡已经可用。SEO、结构化数据、站点地图、robots、`llms.txt`、`ai-summary.txt`、安全响应头与 Cloudflare Pages 自动部署也都已经落地，正式域名为 `pharma.jedliuai.com`。

## 为什么做

原来的 `jedliuai.com` 承载的是更宽泛的个人内容，不适合继续叠加医药外贸的专业定位。新站需要让海外客户、合作伙伴或行业同行快速理解 Jed 在国际业务、注册与质量协调、项目执行和供应链交付中的真实价值，同时避免把雇主、客户、合同、价格、付款和未公开注册信息带到公开网页。

## 值得记住的决策、坑或技术点

- 新站使用独立目录、独立 Git 历史、独立 GitHub 仓库和独立 Cloudflare Pages 项目，旧站代码、部署和 DNS 均未改动。
- 内容表达采用“个人脱敏记录”口径，三组指标和三个案例都配有边界说明，不代表任何雇主的官方披露或对外承诺。
- 英文作为国际业务默认入口，中文使用 `/zh/` 对应路由；canonical、三组 `hreflang`、JSON-LD 和 sitemap 均按这一结构生成。
- 微信弹窗使用原生 `dialog`，支持键盘、Esc 关闭与焦点恢复；移动菜单同样处理了键盘状态和页面滚动。
- 首页头像从约 1.7 MB 的 PNG 优化为约 65 KB 的 WebP，明显改善了移动端加载表现。
- `robots.txt` 不能写非标准的 `LLMs:` 指令，否则 Lighthouse 会判定为无效；保留独立 `llms.txt` 文件即可。
- 最终线上移动端 Lighthouse：Performance 94、Accessibility 95、SEO 100，12 个中英文路由和四个抓取辅助文件均返回 200。

## 一句话亮点

把医药外贸里最难讲清楚的注册、商务与交付协同，做成了一张面向全球合作伙伴的双语专业名片。
