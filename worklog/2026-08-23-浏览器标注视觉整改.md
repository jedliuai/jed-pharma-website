# 浏览器标注视觉整改

## 1. 做了什么

根据局域网页面里的 12 条逐点标注，完成了一轮集中整改：统一处理页头、首屏和页尾的 Jed 品牌标识；放大首页工作台头像；去掉关于区签名中没有语义的横线；把数据区改造成更醒目的深色动态指标卡；让六阶段流程的进度点只随用户选择向前移动；恢复世界地图并让重点国家依次点亮；为英文页面制作三张完整英文化的订单驾驶舱截图；重新把产业生态节点排到圆周上；修复橙色方法论标题的行距；加强 LinkedIn、WhatsApp、WeChat、邮箱和名片入口的品牌色与信息对比度。

## 2. 为什么做

上一版虽然结构已经成立，但局部仍有明显的“模块拼装感”：Logo 白底与页面冲突，数据区没有主次，流程动画缺少含义，市场模块甚至失去了地图，联系信息也过于低调。这一轮的目标不是再换一套风格，而是让已经确认的整体方向真正经得起逐屏检查。

## 3. 值得记住的决策、坑或技术点

- 动效必须解释状态：流程进度点与 1–6 阶段直接绑定，地图标记只在首次进入视口时依次出现，不再做无意义的循环跳动。
- 英文驾驶舱没有简单覆盖几处标题，而是三张图统一术语、统一虚构公司、保留合成数据，确保英文页面看起来像同一套产品。
- 自动抠图工具两次都把透明棋盘格烘焙进图片，没有得到真正的 Alpha 通道，因此没有把错误素材带进项目；第一轮先保留原始 Logo，并针对浅色与深色背景分别采用融合显示方式。
- 第二轮浏览器复查证明“混合模式消除白底”仍会在大尺寸首屏暴露出矩形底色，因此最终改成了真正带 Alpha 通道的透明 PNG；页头和首屏不再依赖背景颜色碰巧一致。
- 数据指标区从深色改回浅色纸张体系，数字用钴蓝和陶土色建立重点，说明文字则提高字号、字重与对比度，避免只有数字可见。
- 地图标记此前使用了比图片更矮的定位层，导致所有纵向坐标整体上移；修复后定位层与 2:1 地图图片严格重合，并给所有标记加白色底座和描边。
- 按英文页暴露出的同一套问题复查中文页后，发现市场窗口、在线工具、个人运营系统、驾驶舱和信息工作流仍有硬编码英文；现在这些界面标签都由语言状态统一控制，中文页面不再混入英文系统标题。
- 中文不能直接沿用英文的大幅负字距和紧行高，因此为中文标题、正文、指标说明、流程面板、工具卡片、方法论与联系区分别设置了更舒展的排版参数，同时不影响英文版。
- 生态图的六个节点改为按角度计算位置，后续文字长短变化时也能继续沿圆周排布。
- 在后续动效复查中，六阶段流程改成进入视口后按稳定节奏自动从 1 走到 6，最后一阶段稍作停留再重新开始；用户手动选择后会优先展示所选阶段，不会马上被自动播放抢走。
- 市场地图的国家标记、四张工作职责卡和在线工具截图都使用一次性的视口触发动画：标记按国家依次点亮，职责卡逐张上移出现，工具截图从轻微虚化过渡到清晰，页面没有滚到对应位置时不提前播放。
- 三张个人订单驾驶舱截图改成自动轮播，鼠标悬停、键盘操作或用户点击时会暂停；手动选择后保留八秒，再恢复自动播放。
- 产业生态图采用“中心开花”的入场方式，六个节点从头像周围依次展开，随后以 56 秒一圈的低速匀速旋转；节点卡片做反向补偿，文字始终保持正向可读。悬停与键盘聚焦时旋转暂停。
- 所有新增动效同时作用于英文和中文页面，并继续尊重 `prefers-reduced-motion`，减少动态偏好的用户会看到稳定静态状态。
- 根据中文页的继续标注，把指标卡、地图标记和产业生态的视口触发点整体后移：用户需要真正进入模块后才开始播放，避免还没看清标题动效就已经结束。指标卡改为整组触发，数字滚动延长到 1.5 秒；地图标记间隔扩大到 280 毫秒；生态节点展开时间延长，并在展开完成后才开始旋转。
- “我实际在做什么”的第二、第四张卡采用更深一档的纸张底色，形成克制的明暗交替，同时保留原来的深色悬停反馈。
- 报价工具和三张订单驾驶舱截图统一加上醒目的橙色放大入口，并实现双语全屏图片预览。预览支持关闭按钮、点击空白区域、Esc 键和关闭后的焦点返回；打开预览时驾驶舱轮播会暂停，关闭后再恢复。
- 这轮只更新了局域网预览，没有提前推送 GitHub 或触发 Cloudflare 部署，先留给自己继续标注确认。

## 4. 一句话亮点

让业务流程自己推进、让市场节点逐个点亮、让产业关系从中心开花——这次动效终于开始讲业务，而不只是装饰页面。
