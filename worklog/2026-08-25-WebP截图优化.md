# WebP 截图优化

今天把中英文站里的订单驾驶舱、报价工具和市场地图共 8 张 PNG 图片转成了 WebP，同时把页面和放大预览里的引用全部切换到新格式。旧 PNG 已从当前版本删除，需要时仍可以从 Git 历史找回。

这次是为了解决滚动到数字工具区域时截图加载明显偏慢的问题。我用质量参数 92 做了偏保守的有损压缩，8 张图的总体积从约 10.69 MB 降到约 0.94 MB，减少约 91%，小字号和界面线条仍保持清晰。

值得记住的是，原来几张图的 HTML 尺寸并不等于真实像素尺寸。这次一并改成了每张图的真实 `width` 和 `height`，并加上异步解码，既减少体积，也避免图片加载后引起布局跳动。

一句话亮点：不牺牲界面细节，把网站核心截图从 10.69 MB 压到 0.94 MB，加载体验直接轻了一个数量级。
